# Sensor semántico y enseñanza situada

Jev es un adaptador de percepción a catálogo tipado, no un agente autónomo ni un oráculo del estado. Pipeline: input humano -> envelope -> candidatos del mundo (entidades y affordances) -> Choice/Noul/Score -> SemanticSignal -> asociación y calibración -> update de creencias / propuesta -> planner -> guardia -> actuador. Separar texto citado, confianza del modelo en interpretación, fiabilidad fuente, likelihood de observación y autorización. Un mensaje puede contener varias observaciones; Unknown es válido. No asumir que Score es probabilidad; preservarlo como evaluación ordinal. Box solo exploración visual.

Tipos conceptuales: Assertion(PropositionDistribution), Reference(EntityDistribution), GoalProposal, ConstraintProposal, Feedback, Unknown. Restricciones humanas y objetivos son propuestas que requieren política de autorización por canal/origen; nunca escriben guardia ni mandos. Contexto mínimo, lenguaje no confiable (prompt injection), catálogos cerrados y rechazo de IDs inexistentes. Mensajes tardíos tienen TTL y versión; no mezclar coordenadas/frames. Deduplicar procedencia común y no contar corroboraciones dependientes como independientes. Bayes discreto sobre fixture con sensibilidad/especificidad separadas; para modelos nuevos aprender likelihood con datos anotados.

Acciones epistémicas AskHuman/Inspect/Remember; estimar valor de información y coste, tiempo, riesgo, no-respuesta. Plantillas locales para preguntas y salida de comunicación, System Two solo para hipótesis o lenguaje abierto fuera de deadline, validación tipada. No emitir consultas sin presupuesto/rate-limit. En robots, stop independiente local; el mensaje no desplaza límite ni emergencia. En Mario el coach no mueve mando directamente. El agente puede usar lenguaje como conocimiento, no como acceso a herramientas.

Aprendizaje incremental sin entrenamiento de modelo obligatorio: evidencia episódica, creencias revisables, estrategia procedimental validada. El grafo de entidades se deriva de observaciones/fuentes, no inventar DB al inicio. Hipótesis de fuente contradicha se corrige; no guardar texto personal ni claves en trace por defecto. Proveedor replay/fixture corre con semilla y manifest. Live Jev opt-in, revisión y endpoint fijados, timeout/cancelación, redacción de entrada, auditoría coste y abstención. Pruebas contra proveedor simulado son contractuales, no prueba de integración live. Si no está disponible registrar NOT_RUN.

Las operaciones semánticas, grounding, memoria y aprendizaje de referencia se distribuyen como core oficial, no como extensiones comerciales. Solo Jev y el transporte son adaptadores externos. El scheduler consume señales versionadas y no bloquea control; el core de comunicación gestiona correlación, TTL, no respuesta y presupuestos. Workflows y planner consumen el mismo contrato de objetivos autorizados.
